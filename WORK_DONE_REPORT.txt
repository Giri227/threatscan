ENCRYPTION DETAILS:
-------------------
Algorithm: Custom encrypAI
Steps:
  1. Reverse the string
  2. Apply Caesar shift (+8)
  3. Jumble (pair front and back characters)

Decryption: Reverse process
  1. Un-jumble
  2. Apply Caesar shift (-8)
  3. Reverse the string
